Monitor annunci immobiliari multi-città

Nato come scraper di stanze in affitto a Catania (raccolta, normalizzazione, deduplica e filtro), è diventato un monitor multi-città che segue gli annunci nel tempo. Gli annunci vengono ripubblicati con id sempre diversi, quindi l'identità dell'immobile è ricavata dall'indirizzo, con storico di foto, caratteristiche e date di prima e ultima comparsa. Viewer web con ricerca, filtri combinabili, preferiti e scarti.

  • Foto deduplicate con hash esatto + hash percettivo (dHash e distanza di Hamming), per riconoscere la stessa immagine ricompressa o con un watermark diverso.
  • Alcuni siti rifiutano ogni richiesta HTTP diretta perché la verifica è legata all'handshake TLS: lì si usa un browser headless reale invece di falsificare gli header.
  • Crash recovery testato dal vivo con kill -9 a metà elaborazione: nessun dato perso né duplicato.
Node.js Playwright Express SQL Server Express nodemailer

Gestore Prenotazioni — biglietteria eventi

Gestionale per la prenotazione di biglietti per spettacoli (teatro, cinema, concerti), pensato come prodotto white-label single-tenant: wizard di setup al primo avvio e nessuna credenziale hardcoded. In migrazione da applicazione console Java a Spring Boot + React, con specifiche e documentazione scritte prima del codice.

  • I tipi di spettacolo si configurano a runtime dall'admin, con campi personalizzati, invece di avere una sottoclasse Java per ogni categoria.
Java Spring Boot React TypeScript Vite Maven
