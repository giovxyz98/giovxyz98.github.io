Patching automatico — Change Request da file CSV

Caricamento massivo da CSV che genera le Change Request di patching, con scarti motivati riga per riga.

Contesto

Funzionalità "Caricamento Massivo": l'upload di un template CSV genera automaticamente le Change Request per le operazioni di patching e aggiornamento software.

Problema

Le richieste di patching venivano aperte a mano una per una: serviva un caricamento da file che generasse le Change Request corrette, scartando le righe non valide con una motivazione tracciata.

Cosa ho fatto

  • Logica di import con funzioni dedicate per creazione delle Change Request, parsing delle date, email di riepilogo e note sulla richiesta.
  • Parsing del CSV lato server leggendo direttamente lo stream dell'allegato (un parser Excel non era utilizzabile nello scope dell'applicazione).
  • Applicazioni abilitate al patching indicizzate in memoria per un lookup rapido, invece di una query per ogni riga.
  • Mapping automatico di categoria, sottocategoria e tipo di change tramite una tabella di mapping dedicata.
  • Validazione riga per riga: una Change Request per ogni tipologia sulla stessa applicazione; scarto di date non valide, tipologie non valide, applicazioni non abilitate e duplicati.
  • Creazione diretta dei record, dopo aver scartato API REST e carrello del catalogo per limiti di autenticazione e di scope.
  • Blocco in submit dei file non CSV e soppressione delle notifiche singole durante l'import.
  • Email di riepilogo HTML con due tabelle: Change Request create e righe scartate con motivazione.
